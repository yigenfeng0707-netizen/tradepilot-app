# TradePilot P2 验收说明

**日期**：2026-10-01  
**范围**：收付汇核销 · 退税三态台账 · 订单毛利报表（MVP，可演示）

## 验收标准

| # | 能力 | 期望 |
|---|------|------|
| 1 | 收付汇登记 | `POST /api/finance/payments` 可对订单写入 in/out |
| 2 | 核销状态 | 按已收 vs 订单总额判定：未核销 / 部分核销 / 已核销 |
| 3 | 退税三态 | `pending` 待申报 → `submitted` 已申报 → `received` 已退税 |
| 4 | 毛利报表 | `GET /api/finance/margin`：收入 − 演示成本(×72%)，含退税估算 |
| 5 | UI | P1 跑通后出现「P2 财务台账」区块，可种子数据 / 登记 / 推进退税 |
| 6 | 冒烟 | `python scripts/smoke_p2.py` → `P2_OK` |

## API 一览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/finance/payments?order_id=` | 收付列表 |
| POST | `/api/finance/payments` | 登记收付 |
| GET | `/api/finance/settlement/{order_id}` | 核销汇总 |
| GET/POST | `/api/finance/rebates` | 退税列表 / 新建 |
| PATCH | `/api/finance/rebates/{id}` | 推进三态 / 改金额 |
| GET | `/api/finance/margin?order_id=` | 毛利报表 |
| GET | `/api/finance/orders/{order_id}` | 订单财务汇总 |
| POST | `/api/finance/demo-seed/{order_id}` | 演示：30% 预付 + 待申报退税 |

## 手工路径（60s）

1. 打开 http://127.0.0.1:8787 →「加载样例 PO」
2. 滚动至 **P2 财务台账** →「写入演示收付+退税」
3. 登记尾款金额至全额 → 状态变为「已核销」
4. 退税台账点「提交申报」→「确认退税」
5. 查看毛利指标与多单报表高亮当前订单

## 数据说明

- 表：`payment_records`、`tax_rebate_claims`（见 `sql/001_schema.sql`）
- 成本：无采购成本字段时用 `DEMO_COST_RATIO=0.72` 估算
- 退税金额：按行项目 HS `rebate_rate`（缺省 13%）× 金额

## 明确延后（P2+）

Celery/Redis、WebSocket、JWT、MinIO、Playwright RPA——本 MVP 不启用。
