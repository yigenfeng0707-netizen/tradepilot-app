# TradePilot P1 规格摘要（数据模型 / 技术栈 / 验收）

## 技术栈（演示版 vs 方案口径）

| 层 | 方案书口径 | 本 MVP |
|----|------------|--------|
| 接入 | FastAPI + JWT + WebSocket | FastAPI（JWT/WS 后置） |
| Agent | Python 类 + LLMClient | `agents/` + `services/llm.py` |
| 编排 | Celery + Redis + 状态机 | 同步流水线（演示足够） |
| 工具 | OCR + Jinja2 + docx/pdf | Jinja2 + MD/HTML；OCR 后置 |
| 数据 | MySQL + MinIO + Redis | SQLite + 本地 `data/` 目录 |

生产迁移：执行 `sql/001_schema.sql` 于 MySQL（微调类型），对象存储换 MinIO 前缀。

## 数据表

完整 DDL 见 [`../sql/001_schema.sql`](../sql/001_schema.sql)（**22 张表**）。

P1 主链路强依赖：`documents` → `document_extractions` → `trade_orders` / `order_line_items` → `contracts` → `generated_docs` → `consistency_checks`，辅以 `agent_tasks`、`audit_logs`、`llm_call_logs`。

## P1 验收主路径

上传 PO（或样例）→ 解析抽取 → 合同草稿 → 一源多单（PI/CI/PL）→ 一致性校验通过 → 交付物可下载/查看。

详见 [`P1-验收用例.md`](./P1-验收用例.md)、[`P1-任务拆解.md`](./P1-任务拆解.md)。
