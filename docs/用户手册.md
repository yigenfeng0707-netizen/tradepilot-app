# TradePilot · 用户手册

**适用版本**：P1 单证闭环 + P2 财务台账 + 可选 P2+（JWT / Celery / MinIO）  
**更新日期**：2026-10-01

---

## 1. 环境要求

- Windows 10+（本文以 PowerShell 为例）
- Python 3.10+
- 可选：Docker Desktop（Redis + MinIO）
- 可选：`MODELSCOPE_API_KEY`（走真实 Qwen；无密钥可 `LLM_MODE=mock`）

---

## 2. 安装与启动

```powershell
cd "D:\APPs\AI模型智能体大赛-余杭\tradepilot-app"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
copy .env.example .env
# 编辑 .env：填写 MODELSCOPE_API_KEY，或设 LLM_MODE=mock
# 录屏/演示建议保持 AUTH_DISABLED=1
uvicorn backend.app.main:app --app-dir backend --host 127.0.0.1 --port 8787
```

浏览器打开：http://127.0.0.1:8787

### 可选 Docker Compose（P2+ 基建）

```powershell
docker compose up -d
# Redis :6379 · MinIO :9000 / Console :9001（默认 minioadmin/minioadmin）
```

将 `.env.example` 中 Celery/MinIO 段复制到本地 `.env` 后开启；详见 [`P2plus-infra.md`](P2plus-infra.md)。

## 3. P1 主路径（单证）

1. 点击 **「加载样例 PO 并跑通全链路」**（或粘贴/上传 PO）。
2. 等待流水线：解析抽取 → 合同草稿 → PI / CI / PL → 一致性校验。
3. 在结果区下载 **合同 / PI / CI / PL PDF**（若已生成）。
4. 可选：**「样例扫描件 OCR→魔搭抽取」**（需 RapidOCR + 密钥）。

期望：一致性校验通过；冒烟 `python scripts/smoke_loop.py` → `CLOSED_LOOP_OK`。

---

## 4. P2 财务路径

P1 跑通后，页面下方出现 **P2 财务台账**：

1. 点 **「写入演示收付+退税」**（约 30% 预付 + 待申报退税）。
2. 在收付表登记尾款至订单全额 → 核销变为「已核销」。
3. 退税台账：待申报 → 已申报 → 已退税。
4. 查看毛利指标（演示成本率 72% + HS 退税估算）。

期望：`python scripts/smoke_p2.py` → `P2_OK`。用例详见 [`P2-验收用例.md`](P2-验收用例.md)。

## 5. 可选：鉴权 / 异步 / MinIO

| 开关 | 默认 | 用法 |
|------|------|------|
| `AUTH_DISABLED=1` | 开 | 关鉴权；设 `0` 且配置 `JWT_SECRET` 后需登录 |
| 测试账号 | — | 用户 `demo` / 密码 `demo`（`POST /api/auth/login`） |
| `CELERY_ENABLED=1` | 关 | 需 Redis；`POST /api/orders/sample?async=1` |
| MinIO | 未配 | 配 endpoint 后可选镜像上传 |

Celery worker（在 `backend/`）：

```powershell
celery -A app.celery_app.celery_app worker --loglevel=info --pool=solo
```

任务进度：`GET /api/tasks/{id}` 或 `WS /ws/tasks/{id}`。

## 7. FAQ

| 问题 | 处理 |
|------|------|
| 健康徽章非「就绪」 | 确认 uvicorn 在 8787；看 `/api/health` |
| LLM 超时 / 失败 | 自动软回退规则模板；或暂设 `LLM_MODE=mock` |
| 鉴权 401 | `AUTH_DISABLED=1`，或先 login 取 Bearer |
| 无 PDF | 确认流水线完成且 `data/outputs/` 可写 |
| Celery 报错 | 确认 Redis 与 worker；默认可不启用 |
| 创空间与本地不一致 | 预期：线上静态、本地全栈（见提交清单） |

更多进度与边界见 [`PROGRESS.md`](PROGRESS.md)。
