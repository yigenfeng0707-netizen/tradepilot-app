# TradePilot P1 验收用例（最小可用）

对齐方案附录 C 样例：`PO-2026-0913`（ABC Trading FZE / LED Panel Light × 5000 / USD 3.20 / CIF Jebel Ali）。

## UC-01 一键样例闭环

**前置**：`uvicorn` 已启动，或直接跑 smoke。

**步骤**：
1. 打开前端首页，点击「加载样例 PO 并跑通全链路」；或 `python scripts/smoke_loop.py`。
2. 等待流水线完成。

**期望**：
- 抽取买方 = `ABC Trading FZE`
- 品名含 `LED Panel Light`，数量 = 5000，单价 = 3.20，总额 = 16000
- 贸易术语 = `CIF Jebel Ali`
- 生成合同草稿文件存在
- 生成 PI / CI / PL 三个交付物
- 一致性校验 `passed=true`
- smoke 打印 `CLOSED_LOOP_OK`

## UC-02 金额交叉校验

**步骤**：使用金额与单价×数量不一致的 PO 文本上传。

**期望**：单价/总额置信度为「中」或告警；校验修复逻辑标注；不静默写错账。

## UC-03 一源多单一致性

**步骤**：跑通样例后读取订单详情中的 PI/CI/PL `fields_json`。

**期望**：三单 `total_amount` 与合同/订单相同（16000）；件数合计 = PO 数量。

## UC-04 LLM 降级

**步骤**：不配置 `LLM_API_KEY`，或设 `LLM_MODE=mock`，跑通样例。

**期望**：流水线仍成功；健康检查 `demo_ready=true`（规则引擎兜底）；响应中标注 `extractor`/`generator` 来源含 `rules` 或 `mock`。

## UC-05 健康检查

**步骤**：`GET /api/health`

**期望**：`ok=true`；返回 `llm_mode`、`demo_ready`；不含密钥明文。

## UC-06 审计链

**步骤**：跑通一次后查询审计（API 或 DB）。

**期望**：至少含 parse / generate / check 相关条目；`entry_hash` 非空且可与 `prev_hash` 成链。
