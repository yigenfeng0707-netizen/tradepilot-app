## 线上（创空间）vs 本地（完整）

| 能力 | 创空间 `*.ms.show` | 本地 `8787` |
|------|-------------------|-------------|
| 形态 | **静态** HTML 样例回放 | **FastAPI** 全栈 |
| P1 上传/解析/合同/一源多单 | 固定样例 JSON 回放 | 真流水线（LLM 或 mock） |
| P2 收付 / 退税 / 毛利 | 浏览器内本地状态演示 | 真 API + SQLite |
| JWT / Celery / MinIO | 无 | 可选开启（见 P2plus） |
| PDF 下载 | 无后端文件 | `data/outputs/` 可下 |
| 构建标记 | 页脚/健康 pill 含 `P2-STATIC-DELIVER-20261001` | — |

**评审建议**：公网先点开创空间看主路径；完整能力与 PDF/财务持久化请按手册起本地，或看 90s 成片。
